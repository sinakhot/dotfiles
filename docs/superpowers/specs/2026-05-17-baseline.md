## 1. Architecture

One bootstrap script bootstraps a known-good shell environment on a fresh box. Four idempotent stages, each guarded by a `SKIP_*` env var. Single source of truth = mise's `config.toml`.

```
  user                   GitHub (sinakhot/dotfiles)
   │                          │
   │  curl install.sh ────────┤
   │                          │
   ▼                          │
[stage 1] bootstrap ──── apt/pacman/brew → git curl fish keychain mise chezmoi
   │
[stage 2] chezmoi init --apply ◄── pulls home/dot_config/* → ~/.config/*
   │
[stage 3] mise install ◄── reads ~/.config/mise/config.toml → ~/.local/share/mise/{installs,shims}
   │
[stage 4] fisher install + chsh -s fish
   │
   ▼
 live shell: fish + starship + zellij + 30+ tools on PATH via mise shims
```

Re-running `install.sh` on any machine syncs to current `main`. Per-stage skip flags allow targeted re-runs / CI matrix.

## 2. Stage 1 — Bootstrap

**File:** `install.sh` (218 lines, bash, `set -euo pipefail`)

**OS detection:** `detect_os()` reads `$OSTYPE`, `/proc/version` (WSL probe), `/etc/os-release`. Returns one of `macos`, `wsl`, `ubuntu`, `arch`, `unknown`. Unknown → hard fail.

**Package install dispatcher:** `pkg_install()` routes to brew / apt / pacman based on detected OS.

**Installed packages:**

| OS | Packages |
|---|---|
| macOS | `git curl fish keychain` (brew auto-installs if missing) |
| ubuntu/wsl | `git curl ca-certificates build-essential fish keychain` (apt) |
| arch | `git curl base-devel fish keychain` (pacman) |

**Post-pkg actions:**

- Register fish in `/etc/shells` if absent
- Install mise via `curl https://mise.run | sh` if missing
- Install chezmoi via `get.chezmoi.io` if missing
- Prepend `$HOME/.local/bin` to PATH for the rest of the script

**Gaps:**

- `keychain` is installed here rather than via mise (per CLAUDE.md: no portable prebuilt binary release upstream). The other stage-1 packages (`git curl build-essential fish`) are correctly OS-level. Recheck keychain on each major refresh in case upstream starts shipping a `ubi:`-friendly release.
- No verification that `/etc/shells` write actually succeeded (silent on failure).

## 3. Stage 2 — Dotfiles (chezmoi)

**Command:** `chezmoi init --apply --branch $DOTFILES_BRANCH $DOTFILES_REPO`
**Re-entry:** if `~/.local/share/chezmoi/.git` exists, calls `chezmoi update --apply` instead.

**Source convention:** `.chezmoiroot` = `home`. Files under `home/dot_X` apply to `~/.X`.

**Managed configs (current state):**

**Gaps:**

- `nvim/` is an empty directory. Neovim is installed via mise but has no managed config — falls back to LazyVim's default if user runs `nvim` after install.

- No managed `~/.config/git/config` or `.gitconfig` — git identity left to manual setup per machine.
- No managed `~/.ssh/config`.
- No machine-specific overlay system — chezmoi templating exists in stack but is unused (no `.tmpl` files). CLAUDE.md mentions "private chezmoi data file or out-of-band" for secrets but no skeleton.

## 8. Conventions (cross-cutting)

Per CLAUDE.md, enforced informally:

- **Bash, not POSIX sh.** `set -euo pipefail`. No silent error swallow except chsh in CI and fisher warnings.
- **No secrets in repo.** Public-safe defaults only. Machine-specific values gated by chezmoi template or out-of-band private overlay.
- **Edit either side, mirror back.** Editing live config under `~/.config/<app>` requires `chezmoi re-add` to sync to source.
- **Don't commit `~/.local/share/chezmoi`.** That's the clone; this repo is source of truth.
- **Distinguish the two checkouts.** `~/Projects/sinakhot/dotfiles` = upstream source (where you commit + push). `~/.local/share/chezmoi` = chezmoi's clone of `origin/main` (where `chezmoi apply` reads from). They are different working copies — edits to one do not flow to the other without a push + `chezmoi update`.

**Gap:** the two-checkout distinction is not documented in CLAUDE.md. Caused real confusion in 2026-05-17 session (yazi line missing from live mise config because commit wasn't pushed; later a stash conflict in the clone needed manual cleanup).

## 9. Consolidated gap list

Ranked by impact, lowest-hanging first.

1. **No managed yazi config.** Add `home/dot_config/yazi/{yazi,keymap,theme}.toml`. Currently relying on defaults — fragile if defaults shift.
2. **No managed nvim config.** Empty `nvim/` dir misleads. Either populate (LazyVim init) or delete the placeholder.
3. **No `fish_plugins` checked in.** Stage 4 installs fisher then installs nothing.
4. **Two-checkout pitfall undocumented.** Add a section to CLAUDE.md explaining the source-vs-clone distinction.
5. **CI doesn't smoke-test the public URL.** Add a weekly job that `curl`s `dotfiles.sinakhot.com/install.sh` and diffs against `main`.
6. **CI doesn't exercise full apply path on macOS/Arch.** Promote both to `with-dotfiles` scope.
7. **`ubi:` backend deprecation.** Mass-rename to `github:` before mise 2027.1.0.
8. **No mise version pinning.** Decide whether reproducibility matters and pin (or accept `latest`).
9. **No git/ssh config under chezmoi.** Decide whether identity-bearing files belong in this public repo (probably not — but a private overlay skeleton would help).
10. **`cargo-binstall` is unused** in the mise registry. Either remove or document the intended use.
